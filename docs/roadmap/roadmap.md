# 路线图

本文件只写还没做的事、它们的产品结果和完成标准。完成一项删一项，历史由 git 记录。

## 状态说明

- 目前所有版本都是 Alpha：不承诺功能稳定，不承诺文件格式稳定；格式变化必须带迁移，不能丢数据。
- 1.0 不是一个进度点，是一个承诺：到了 1.0 就要开始长期维护——格式向后兼容、接口不轻易破坏、问题要被修复。
- 所以 1.0 不在计划内，也不设时间。进 1.0 的条件是核心模型稳定，并且愿意承担维护成本。
- Alpha 期间允许实验：功能可以推翻重做，格式可以破坏。
- 迁移以发版为颗粒度：开发期间的格式变化不写迁移；只有本次发布与上一次发布格式不同时，才提供迁移。用户数据不能丢。
- 每个对外发布都要归档该版本的格式样例文件，作为后续迁移测试的输入。

## 0.2.0 之后还没做的事

七类块、撤销、多选对齐、层级、画板首页、标签、搜索、自动保存、崩溃恢复、容器与 HTML 导出的主体已经在 0.2.0-alpha.1 交付。下面是没有收掉的尾巴。

- 列表缩略图：保存时生成一张缩略图，首页与打开画板的第一帧直接读图，不碰原文件。完成标准：首页一万条不因为缩略图变慢；缩略图损坏时回落到文字行。
- 当前画面的 PNG 导出：把视口里的内容导出成一张图。完成标准：浅色深色各导一张，内容与画布一致。
- 标签筛选：首页按标签过滤列表，标签可多选。完成标准：选中两个标签时取交集；清空筛选回全量。
- 一万条笔记的预算实测：列表 ≤1.5s、搜索 ≤100ms、冷启动 ≤500ms、空闲内存 ≤200MB。完成标准：给出实测数据，超预算写明原因。
- 未知字段原样保留与迁移骨架：读到不认识的字段留着，写回时照抄；格式升级时进迁移流程。完成标准：伪造一份带未知字段的文件，读写一轮后字段还在。
- 视频与音频的内置播放：在画布上直接播放。完成标准：常见格式能播、能暂停、不卡输入。
- 真机交互验收：拖动/旋转手柄、颜色与字体弹层、多选操作条在真实鼠标下的表现。完成标准：逐项走一遍并记录。

## 以后

- 手写笔迹与 iPad 版：核心用 Rust，UI 层按平台换
- 网页裁剪：抓正文转成物件，不做网页快照
- 表格计算
- 标尺、网格、参考线
- 组合
- 内部链接与反向链接
- PDF 导出与打印排版，属于导出器的升级
- 搜索图片中的文字、音频转写
- 版本历史
- 把跨应用通用的 UI 组件与文本编辑内核抽成独立库，等出现第二个 Rust 应用时再做
- 插件：新物件类型与导入导出器，不做任意代码
- 协作与同步：可选、非必需、内容端到端加密

## 不做

- 3D 与动画
- 任意代码插件
- Alpha 阶段不做移动端
- 遥测，以及任何形式的笔记内容上传
