# 路线图

本文件只列还没做的事和它们的顺序。完成一项就删掉一项，历史由 git 记录。

## 原则

- 数据本地化：内容只存在用户磁盘，联网只用于检查更新。
- 能力对等：纸笔能做的事都要能做；数字独有的能力（搜索、撤销、视频音频）是额外收益。
- 计划不写日期与进度：只有先后顺序，没有时间承诺。

## 现状

- 仓库：Rust workspace 骨架（core / store / ui / app），CI（rustfmt、clippy、test）与 CodeQL 已启用。
- 规则：AGENTS.md 入口，加三个 skill（project-rules、git-commit、ui-design），另引入 skill-creator 作为基线。
- 设计：产品定位、物件模型、私有容器格式、导出器、字体策略、隐私边界已定；数据模型细节与技术选型未定。

## 阶段 1：数据模型与格式规范

把画布上的东西变成能稳定存放、能长期迭代的规范。

- 文档模型：画布、物件类型与属性（位置、尺寸、旋转、层级、锁定）
- 富文本表示：段落、字符样式、对齐
- 多媒体物件：图片、视频、音频的存储与元数据
- 容器结构：清单、媒体、缩略图、未知物件原样保留
- 版本与升级：读旧写新、迁移链、旧应用拒绝新文件
- 产出：格式规范 v1，以及序列化、反序列化、迁移的参考实现

## 阶段 2：技术选型

确定画布与文本编辑的实现底座，选型结论必须由需求验证，而不是靠印象。

- 候选：iced、egui、slint
- 门槛：能自绘画布、能做可编辑文本框、中文输入法可用、拖拽达到 60fps
- 产出：选型结论，加一个最小原型（一张画布、一个可拖动可输入的文本框）

## 阶段 3：画布内核

- 无限画布：缩放（纯视图）、平移、适应内容、回到 100%
- 物件操作：命中测试、选中、拖动、缩放、旋转、多选
- 层级：置顶、置底、上移、下移、锁定
- 对齐：拖动吸附辅助线，多选对齐与等距分布
- 撤销重做：覆盖全部物件操作的命令栈

## 阶段 4：文字编辑

- 文本框：创建、拖动、缩放、自动换行
- 编辑：光标、选区、删除、复制粘贴、中文输入法
- 富文本：字体、字号、颜色、加粗、对齐
- 字体：内置字体集、系统字体枚举、用户导入、缺字回退

## 阶段 5：物件类型

- 图片：插入、拖动、缩放、旋转、裁剪、叠放
- 视频与音频：插入与播放
- 表格：简单编辑（计算留到以后）
- 形状：矩形、圆、直线、箭头
- 高亮：半透明色块

## 阶段 6：持久化与找回

- 自动保存、原子写、崩溃恢复
- 笔记列表（缩略图）、标签、置顶
- 搜索：文字物件的内容检索

## 阶段 7：导出器

- 私有容器导出（自包含、内嵌媒体）
- 图片导出：范围、分辨率、透明背景
- HTML 导出：布局保真、能看能播、导出前预检与降级报告

## 阶段 8：发布准备

- 内置字体清单与许可整理
- 安装包、签名、发布校验值
- 更新检查：仓库下载源，不静默更新
- 发布流程落进 git-commit skill

## 以后

- 手写笔迹与 iPad 版（核心用 Rust，UI 层按平台换）
- 网页裁剪：抓正文转物件，不做网页快照
- 表格计算
- 标尺、网格、参考线
- 组合
- 内部链接与反向链接
- PDF 导出与打印排版（导出器的升级）
- 搜索图片中的文字、音频转写
- 版本历史
- 插件：新物件类型与导入导出器，不做任意代码
- 协作与同步：可选、非必需、内容端到端加密

## 不做

- 3D 与动画
- 任意代码插件
- v1 的移动端
- 遥测与任何形式的笔记内容上传
