# 路线图

本文件只写还没做的事、它们的产品结果和完成标准。完成一项删一项，历史由 git 记录。

## 状态说明

- 所有版本都是 Alpha：不承诺功能稳定，不承诺文件格式稳定；格式变化必须带迁移，不能丢数据。
- 1.0 不是一个进度点，是一个承诺：到了 1.0 就要开始长期维护——格式向后兼容、接口不轻易破坏、问题要被修复。
- 所以 1.0 不在计划内，也不设时间。进 1.0 的条件是核心模型稳定，并且愿意承担维护成本。
- Alpha 期间允许实验：功能可以推翻重做，格式可以破坏。
- 迁移以发版为颗粒度：开发期间的格式变化不写迁移；只有本次发布与上一次发布格式不同时，才提供迁移。用户数据不能丢。
- 每个对外发布都要归档该版本的格式样例文件，作为后续迁移测试的输入。

## 0.2.0 之后还没做的事

七类块、撤销、多选对齐、层级、画板首页、缩略图、标签与筛选、搜索、自动保存、崩溃恢复、索引、未知字段保留、迁移骨架、容器/HTML/PNG 导出都已在 0.2.0-alpha.1 交付，交付的是内核与数据层，界面要由新界面重写。下面是没有收掉的尾巴。

- 视频与音频的内置播放：在画布上直接播放。完成标准：常见格式能播、能暂停、不卡输入。
- 外部改动发现得更准：数据层按 boards/ 目录时间与文件数判断，能发现新建、删除与改名；原地覆盖写、块文件与缩略图的变化发现不了，要靠强制重建索引。完成标准：外部改内容或元数据后不点刷新也能在列表里看到。
- 自动保存的索引成本：旧界面测量，一万张画板时每次保存整份重写索引约 42ms。完成标准：改成延迟或增量落盘，自动保存不因此变慢。
- 真机交互验收：拖动/旋转手柄、颜色与字体弹层、多选操作条、拖放媒体在真实鼠标下的表现。完成标准：逐项走一遍并记录。
- 内存预算口径要重新定：旧界面进程工作集 237MB，低于同机空 eframe 窗口的 261MB，说明 200MB 预算被图形栈基线占满。完成标准：改成可测口径（框架基线之上的增量或堆统计），并给出该口径下的数字。
- 端到端输入延迟：只有旧界面的帧时间下界（p95 17.2ms），量不到系统合成与显示延迟。完成标准：给出真实输入到可见的数字，或说明为什么这个环境量不了。
- 冷启动预算口径：旧界面一万张画板实测 514–534ms，预算 500ms；其中约 470ms 是窗口与图形栈初始化，应用自身加载约 30–46ms。完成标准：与内存一样定一个可测口径，或者给出压框架固定成本的办法。

### 界面：册、页、书架

册是基础单位，页在册里，书架是看册的一种筛法。数据层已有页与册的归属、册与书架的引用；界面按 `docs/design/ui.md` 的「层与动线」重写：

- **首页封面墙**：册的封面铺开，顶栏是书架筛选与新建。完成标准：新建页同时建出一册并直接进画布；新建册得到空册；名字不写就不产生文件。
- **册内合并**：页列表与画布同屏，装订、移出、插入、归并、页序都在列表栏。完成标准：`LibraryView`、`VolumeView`、`ShelfView` 三个视图删掉之后没有功能丢失。
- **架的合成与排他**：架由两册合成，界面不再直接建空架；上架到第二层即移动；册清零时架进回收站。完成标准：界面没有「新建书架」入口；一本册只在一层手动架上。
- **Empty book 不进界面**：册列表不列编号 0；它有页时以「未归档」一行出现。完成标准：全新工作区的首页没有 Empty book。
- **册封面**：取这本册第一页的缩略图。完成标准：没有缩略图时显示纸色空封面，不显示破图。
- **册内排序**：调整页在册里的顺序。完成标准：顺序写回册文件，重启后不变。
- **还原回原册原位**：回收站条目记下原册编号与原位置。完成标准：删页后还原回到原册原位；原册不在了，落进新册。
- **图书馆层级**：书架之上再加一层。完成标准：先不做，等「书架多到找不着」真实发生。

### 界面：工具栏

- **富工具栏的上下文**：没选中时工具栏是"新内容的默认值"，选中某个块时同一排改成"调这个块"。完成标准：选中前后工具栏位置不动、只换内容；块上浮的那条最终取消。
- **工具栏扩容**：把常用动作继续往上收，减少"到处找"。完成标准：日常编辑不需要打开菜单。

### 界面：基础设施

- **布局小工具**：视图用布局系统排布，不手工计算像素坐标。完成标准：新增视图里不出现手算坐标。
- **左侧栏底部的设置入口**：回收站的数据层已落地，界面待新界面重写；设置还没有任何可设的项，等有了再放。完成标准：设置项为空时不放出来。

### 主题与外观

- **画布配色进 token**：画布配色还没进主题 token。完成标准：主题能覆盖画布颜色。
- **深色主题**：单独设计，不从浅色反推。完成标准：深色有自己的一套表面层次与边框策略，不是浅色的反色。
- **高对比外观**：完成标准：正文对比度达标且布局不破。
- **字重与等宽数字**：界面改用 Web，字重与等宽数字由 CSS 提供。完成标准：标题用 600 字重，时间等数字用等宽。

### 需要产品决策

- **纸张样式**（空白 / 横线 / 方格 / 点阵）：要先定它存在哪、是否随笔记走。
- **日期库**：数据层只存时间戳，界面还没有"今天/本周"分组与绝对时间。引入日期库属于新增依赖。
- **置顶**：要在笔记文件里加字段，属于格式变更。
- **统一标签**：笔记与媒体共用一套标签。要先定标签存在哪（画板格式加字段，还是工作区单开媒体元数据文件），单独一轮做。
- **资源库里的复用出处**：索引记了引用它的画板集合；界面展开出处还没做。完成标准：资源行能展开出处，点一下跳到那张笔记。
- **exe 文件图标**：Tauri 壳的 `build.rs` 会按 `bundle.icon` 内嵌应用图标；要出包后在资源管理器里确认，确认后删除本条。
