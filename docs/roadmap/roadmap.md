# 路线图

本文件只写还没做的事、它们的产品结果和完成标准。完成一项删一项，历史由 git 记录。

## 状态说明

- 目前所有版本都是 Alpha：不承诺功能稳定，不承诺文件格式稳定；格式变化必须带迁移，不能丢数据。
- 1.0 不是一个进度点，是一个承诺：到了 1.0 就要开始长期维护——格式向后兼容、接口不轻易破坏、问题要被修复。
- 所以 1.0 不在计划内，也不设时间。进 1.0 的条件是核心模型稳定，并且愿意承担维护成本。
- Alpha 期间允许实验：功能可以推翻重做，格式可以破坏。
- 迁移以发版为颗粒度：开发期间的格式变化不写迁移；只有本次发布与上一次发布格式不同时，才提供迁移。用户数据不能丢。
- 每个对外发布都要归档该版本的格式样例文件，作为后续迁移测试的输入。

## 0.2.0 之后还没做的事

七类块、撤销、多选对齐、层级、画板首页、缩略图、标签与筛选、搜索、自动保存、崩溃恢复、索引、未知字段保留、迁移骨架、容器/HTML/PNG 导出都已在 0.2.0-alpha.1 交付。下面是没有收掉的尾巴。

- 视频与音频的内置播放：在画布上直接播放。完成标准：常见格式能播、能暂停、不卡输入。
- 缩略图反映整张画板：现在是当前视口的一张图。完成标准：不改变用户当前视图也能拍出内容全貌；画板很大时仍然可读。
- 运行期间发现外部改动：现在只在打开工作区时校验一次索引。完成标准：外部新增/修改/删掉画板后，不重开工作区也能在列表里看到。
- 自动保存的索引成本：一万张画板时每次保存整份重写索引约 42ms。完成标准：改成延迟或增量落盘，自动保存不因此变慢。
- 真机交互验收：拖动/旋转手柄、颜色与字体弹层、多选操作条、拖放媒体在真实鼠标下的表现。完成标准：逐项走一遍并记录。
- 输入延迟与空闲内存的预算实测：只测过列表、搜索与启动。完成标准：补齐两项数字，超预算写明原因。

## 以后

- 手写笔迹与 iPad 版：核心用 Rust，UI 层按平台换
- 网页裁剪：抓正文转成物件，不做网页快照
- 表格计算
- 标尺、网格、参考线
- 组合
- 内部链接与反向链接
- PDF 导出与打印排版，属于导出器的升级
- 搜索图片中的文字、音频转写
- 版本历史
- 把跨应用通用的 UI 组件与文本编辑内核抽成独立库，等出现第二个 Rust 应用时再做
- 插件：新物件类型与导入导出器，不做任意代码
- 协作与同步：可选、非必需、内容端到端加密

## 不做

- 3D 与动画
- 任意代码插件
- Alpha 阶段不做移动端
- 遥测，以及任何形式的笔记内容上传
