# 路线图

本文件只写还没做的事、它们的产品结果和完成标准。完成一项删一项，历史由 git 记录。

## 状态说明

- 目前所有版本都是 Alpha：不承诺功能稳定，不承诺文件格式稳定；格式变化必须带迁移，不能丢数据。
- 1.0 不是一个进度点，是一个承诺：到了 1.0 就要开始长期维护——格式向后兼容、接口不轻易破坏、问题要被修复。
- 所以 1.0 不在计划内，也不设时间。进 1.0 的条件是核心模型稳定，并且愿意承担维护成本。
- Alpha 期间允许实验：功能可以推翻重做，格式可以破坏。
- 迁移以发版为颗粒度：开发期间的格式变化不写迁移；只有本次发布与上一次发布格式不同时，才提供迁移。用户数据不能丢。
- 每个对外发布都要归档该版本的格式样例文件，作为后续迁移测试的输入。

## A1 能开机

- 目标：一张空白画布上能写、能存、能原样打开。
- 范围：数据模型与容器格式、画布平移与缩放、可输入的文本框、字体基础、保存与打开。
- 退出标准：新建 → 输入一段中文 → 保存 → 关闭 → 重开，内容、位置、字体全部还原；门禁三条全绿。
- 不在范围：图片、视频、表格、搜索、导出。
- 依赖：无。

## A2 能贴能放

- 目标：画布上能放图片、视频、音频和形状，能叠、能对齐、能反悔。
- 范围：媒体物件、形状与高亮、层级与锁定、多选与对齐分布、撤销重做。
- 退出标准：插入图片、视频、音频并能播放；多选后能对齐与等距分布；任意操作可撤销；重开后一致。
- 不在范围：文字高级排版、导出。
- 依赖：A1。

## A3 能找得到

- 目标：笔记多起来之后仍然找得到。
- 范围：笔记列表与缩略图、标签、置顶、文字搜索、自动保存、崩溃恢复。
- 退出标准：一万条笔记下列表可用、搜索落在项目性能预算内；强制结束进程后重开，数据不丢。
- 不在范围：手写识别、媒体内容检索。
- 依赖：A1。

## A4 能带出去

- 目标：内容能离开这个应用，且带走之后仍然完整。
- 范围：私有容器导出、图片导出、HTML 导出、导出预检与降级报告。
- 退出标准：导出的 HTML 在另一台机器打开，布局与内容一致；容器导出再导入无损。
- 不在范围：PDF、打印排版、SVG。
- 依赖：A2。

## 以后

- 手写笔迹与 iPad 版：核心用 Rust，UI 层按平台换
- 网页裁剪：抓正文转成物件，不做网页快照
- 表格计算
- 标尺、网格、参考线
- 组合
- 内部链接与反向链接
- PDF 导出与打印排版，属于导出器的升级
- 搜索图片中的文字、音频转写
- 版本历史
- 插件：新物件类型与导入导出器，不做任意代码
- 协作与同步：可选、非必需、内容端到端加密

## 不做

- 3D 与动画
- 任意代码插件
- Alpha 阶段不做移动端
- 遥测，以及任何形式的笔记内容上传
