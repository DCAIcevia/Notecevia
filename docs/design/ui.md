# 界面

## 主题层

| 文件 | 职责 |
| --- | --- |
| `crates/ui/theme/base.css` | 与主题无关的基础规则：重置、可读性、焦点、动效降级 |
| `crates/ui/theme/default.css` | 默认主题的变量定义，一个主题一个文件 |

- 组件只引用变量，不写死颜色、字号、间距与动效时长。
- 变量分六组：表面、文字、线、语义、排版与间距、动效与层叠。
- 语义色只保留强调与危险；警告与成功在有使用方时再加。
- 只维护一套外观时不与系统外观联动，因此不写 `prefers-color-scheme`。
- 深色与高对比各自是独立的一整套：表面层次、悬停方向、语义色对比都要重新定，不是同一套换值。
- 动效时长由变量控制，`prefers-reduced-motion` 下归零，关掉后信息不丢。

## 组件的优先级

- 界面优先以组件实现：结构、样式、布局在组件里定清楚，视图只做拼装。
- 基础组件放在 `crates/ui/components/base/`，文件名用 `Base` 前缀。
- 基础组件不带业务：不调 IPC、不读工作区、不认画板与册。
- 组件只引用主题变量，不写死取值。
- 一个控件在第二个视图里出现时，才抽成组件；只出现一次的先留在视图里。

| 组件 | 用途 |
| --- | --- |
| `BaseButton` | 四种变体与两档尺寸，禁用态 |
| `BaseTextField` | 单行输入，错误信息紧贴字段 |
| `BaseSearchField` | 搜索输入，停手后按去抖发一次查询 |
| `BaseCheckbox` | 勾选，选中用字形区分而不只是颜色 |
| `BaseProgress` | 确定与不确定进度 |
| `BaseSpinner` | 一秒内的等待 |
| `BaseEmptyState` | 空态，必须带下一步 |

## 静态与动态

- 静态内容的成本低于动态内容：静态内容布局一次即可复用，动态内容每帧都要重算。
- 同一时间只有一个交互主体：编辑、拖拽、选区、输入同时只发生在一个元素上，其余元素是静态的。
- 渲染分两层：静态层是已定稿的内容，布局后转为缓存或位图，滚动与缩放只改变换；动态层是当前交互的那一个元素。
- 视口外的内容不布局、不绘制，列表与画布都按视口裁剪。
- 预加载跟随指针，并做去抖，避免指针每移动一次就触发一次加载。
- 判断标准：一帧内需要重算的只有正在交互的那一个，其余来自缓存或变换。

## 阴影与圆角

- 阴影只做贴边：最大模糊半径 6px，最多三层，不做大扩散；浮起来的效果是错的。
- 每条阴影由两种成分组成：一层 0 模糊的硬边，加一到两层 1–6px 的近投影。边缘清楚，元素看着是压在纸上，不是飘着。
- 有边框的控件只加近投影，不再叠 0 模糊的硬边。无边框的表面靠硬边代替边框，不出现 border 与阴影同时画边。
- 层级越高阴影越深，但模糊半径不跟着放大：`control` → `raised` → `overlay` → `modal` 的差别在浓度，不在扩散。
- 圆角四档：`sm` 4px、`md` 6px、`lg` 8px、`xl` 12px，另有一档 `pill`。
- 嵌套时内层圆角 = 外层圆角 − 内边距，最小 2px；不内缩就会出现尖角。

## 视图与画布

| 视图 | 文件 | 内容 |
| --- | --- | --- |
| 首页 | `crates/ui/views/HomeView.vue` | 画板列表、新建画板、加载与错误态、空态 |
| 画板 | `crates/ui/views/BoardView.vue` | 顶栏、画布视口、工具条、缩放控件、打开失败重试 |
| 册与书架 | `crates/ui/views/LibraryView.vue` | 册列表与书架列表、新建与删除 |
| 册内 | `crates/ui/views/VolumeView.vue` | 装订画板、移出、调整页序 |
| 书架 | `crates/ui/views/ShelfView.vue` | 把册上架与移出 |
| 回收站 | `crates/ui/views/TrashView.vue` | 还原、彻底删除、清空 |

- 画布两层：视口层只做平移与缩放，靠 `transform` 完成；块层按世界坐标绝对定位，缩放不触发重排。
- 块在 `crates/ui/canvas/CanvasBlock.vue` 绘制，种类由正文的 `kind` 决定；视频与音频共用 `media` 正文。
- 媒体按内容哈希取一次，同一哈希复用同一个 ObjectURL。
- 数据从 `crates/ui/api/` 进出：`types.ts` 对应 IPC 形状，`client.ts` 只做参数与错误规整。
- 地址带 `?mock` 且是开发构建时，前端改用 `crates/ui/api/mock.ts` 的假数据；生产构建不包含这段。
- 图标从 `crates/ui/icons.ts` 取。包根 `@lucide/vue` 会静态引入整份图标目录（三千多个模块），
  开发期会把模块图撑到两千个请求，首屏内容要多等约两秒。
- 首页缩略图按行加载：进视口才读，不在启动时把整个库读一遍。

## 布局

- 窗口是一块底：底色 `--color-surface-app`，四周内缩 `--space-3`。
- 内容放在岛上：`.island` 是白底、`--radius-xl` 圆角、`--shadow-hairline` 最轻一档阴影。
- 岛与岛之间留 `--space-3` 的缝，不贴边、不共用边框；嵌套只到两层（窗口 → 岛）。
- 内容页（首页、册与书架、册内、书架、回收站）是一列居中的岛，最宽 820；画板页的岛铺满，因为画布要空间。
- 列表不画卡片：行与行之间 1px 的 `--color-line`，悬停只提底色；行用负边距把文字与上方标题对齐。
- 岛内留白：上下一档 `--space-4`，左右 `--space-6`。
- 悬浮件（工具条、缩放、浮层）单独成岛，用 `--shadow-overlay`，比内容岛高一档。

## 布局

- 这是应用窗口，不是网页：窗口的每一寸都属于应用，不做居中一列的版面。
- 骨架是「常驻侧栏 + 铺满的内容面板」：`crates/ui/layout/AppShell.vue`。
- 窗口是一块底：底色 `--color-surface-app`，四周内缩 `--space-2`；侧栏与内容面板之间也是 `--space-2` 的缝。
- 侧栏宽 204，放应用名与三处导航（画板、册与书架、回收站），当前项用底色标出。
- 内容面板是白底、`--radius-xl` 圆角、`--shadow-hairline`；页内顶栏贴在面板顶部（`border-bottom` 一条线），主体滚动发生在这里。
- 画板页不走侧栏骨架：工具条与画布各占一块，画布铺满剩余空间。
- 列表不画卡片：行与行之间 1px 的 `--color-line`，悬停只提底色；行用负边距把文字与上方标题对齐。
- 悬浮件（工具条、缩放、浮层）单独成岛，用 `--shadow-overlay`，比面板高一档。

## 画布交互

| 操作 | 结果 |
| --- | --- |
| 点块 | 选中，只加一圈描边，不改几何 |
| 拖动块 | 改世界坐标；锁住的块只选中、不移动 |
| 拖动空白 | 平移视图 |
| Ctrl 滚轮 | 以指针为中心缩放 |
| Esc | 取消选中 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做，一次手势算一步 |
| 双击文本块 | 进编辑，输入法照常；Esc 或点别处提交 |
| Delete / Backspace | 删除选中的块 |
| 底部工具条 | 在视口中心新建文本、形状、表格、高亮，插入媒体 |
| 顶部圆点手柄 | 拖动旋转；角度按块中心算 |
| 顶栏「导出」 | 导出容器与自包含 HTML，路径显示在顶栏 |
| 首页「刷新」 | 强制重建索引，用于外部改动后刷新列表 |

- 顶栏右侧是存盘状态：`已保存`、`未保存`、`保存中`、`保存失败`；失败时显示原因并常驻，直到下一次存盘成功。
- 落盘间隔取应用配置的 `autosave.intervalMs`；失败不自动重试，下一次改动或手动重试才排期。

## 入口

- `crates/ui/main.ts` 依次引入主题文件与基础规则，挂上 pinia 与路由后挂载 `App.vue`。
- `App.vue` 只放 `RouterView`。
- `crates/ui/preview/UiPreview.vue` 是界面验收页：主题变量与基础组件摊开显示。
