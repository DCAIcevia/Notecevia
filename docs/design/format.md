# 格式规范

范围：工作区存储与导出容器。规范公开，其他软件可据此实现读写。

## 基本单位

- 一切内容都是块（block）。文本是块，图片是块，视频、音频、表格、形状、高亮都是块。
- 块分两类：**共享块**按内容寻址，多篇笔记引用同一份；**私有块**按 id 命名，随笔记走。
- 共享块：图片、视频、音频。私有块：文本、表格、形状、高亮。

## 画板

- 一个画板 = 一篇笔记。
- 画板只存目录，内容在块里；目录项记录块类型、块地址与摆放。
- 画板字段：格式版本、画布范围、目录项、媒体表、缩略图。

## 目录项

| 字段 | 说明 |
| --- | --- |
| `id` | 目录项标识，稳定不变 |
| `block_type` | 块类型编号 |
| `reference_mode` | `own` 持有、`live` 同步引用、`snapshot` 快照引用 |
| `block_ref` | 块地址；工作区内是相对路径，容器内是偏移与长度 |
| `transform` | 画布位置、尺寸、旋转 |
| `z_index`、`locked`、`visible` | 层级与状态 |
| `bbox` | 包围盒，用于视口加载与空间索引 |

## 引用

| 模式 | 是否随源变化 | 引用处能否编辑 |
| --- | --- | --- |
| `own` | —— | 能 |
| `live` | 随源更新 | 不能，只能跳转到源 |
| `snapshot` | 不随源更新 | 能，改的是自己那份 |

- 媒体的引用默认是 `snapshot`。
- 禁止链式引用：引用只能指向块，不能指向另一个引用。
- 禁止自引用：画板不能引用自己。
- 源块被删除时，先列出所有引用处；强行删除后，引用保留最后一次内容并标记为悬空。

## 块

- 共享块：按内容哈希命名，不可变；换一张图就是新哈希、新块。
- 私有块：按 id 命名，可编辑；编辑后写回同一 id。
- 块内容编码：CBOR。
- 二进制格式必须提供检查工具，能把容器与块转成人可读的结构树。

## 块类型

| 编号 | 类型 | 共享 | 内容 |
| --- | --- | --- | --- |
| 1 | 文本 | 否 | 富文本段落：文字、字符样式（字体、字号、颜色、粗体）、对齐、内边距 |
| 2 | 图片 | 是 | 媒体引用、裁剪区域、填充方式 |
| 3 | 视频 | 是 | 媒体引用、封面帧、播放设置 |
| 4 | 音频 | 是 | 媒体引用、封面帧、播放设置 |
| 5 | 表格 | 否 | 行列、单元格内容（内嵌文本，不引用其他块） |
| 6 | 形状 | 否 | 几何参数、描边、填充 |
| 7 | 高亮 | 否 | 颜色、透明度 |

编号 100 以上留给扩展。

## 工作区布局

```text
工作区/
  boards/<board-id>.board       目录（CBOR）
  blocks/<block-id>.block       私有块（CBOR）
  media/<sha256>                共享块原始字节
  thumbnails/<board-id>.png     画板缩略图
  index.sqlite                  搜索索引，可删除后重建
  .trash/                       回收站
```

- 工作区就放在程序所在目录的 `NoteceviaData` 里，随程序走：整个文件夹拷走就换了机器。
- 程序目录不可写时打开失败并提示路径，不把数据偷偷写到别处——悄悄换了位置，用户以后找不到自己的笔记。
- 媒体不进入索引库，索引只记元数据。
- 索引损坏时删除重建，不影响内容。
- 拖入的媒体托管复制进媒体池，不引用外部路径。

## 已落盘的字段

文本块与画板目录已经按上面这套编号落盘。画板文件是 `boards/<board-id>.board`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `format` | 整数 | 格式版本，当前为 1 |
| `kind` | 文本 | 固定为 `board` |
| `title` | 文本 | 画板标题 |
| `entries` | 数组 | 目录项，见下表 |

目录项：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | 整数 | 目录项标识，删掉也不复用 |
| `block_type` | 整数 | 块类型编号 |
| `block_ref` | 文本 | 相对路径，正斜杠分隔 |
| `x`、`y`、`w`、`h` | 浮点 | 世界坐标里的位置与尺寸 |
| `rotation` | 浮点 | 绕块中心顺时针旋转的弧度，可省，默认 0 |
| `z_index` | 整数 | 层级 |

文本块是 `blocks/<id>.block`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `format` | 整数 | 格式版本，当前为 1 |
| `block_type` | 整数 | 1 |
| `id` | 整数 | 块标识 |
| `text` | 文本 | 正文 |
| `size` | 浮点，可省 | 字号；省掉表示跟随主题 |
| `color` | 文本，可省 | 文字颜色 `#rrggbb`；省掉表示跟随主题 |
| `background` | 文本，可省 | 文字底色 `#rrggbb`；省掉表示没有底色 |

- 编码是标准 CBOR，一律定长形式，映射的键是文本。文档顺序即写入顺序。
- 写盘顺序是先块后画板，每个文件先写 `.tmp` 再改名。画板文件最后落地，所以中途失败最多留下没人引用的块。
- 块地址来自文件，不能直接当路径用：绝对路径与 `..` 一律拒绝，只接受工作区内的相对路径。
- 画板文件的 `format` 更高时拒绝打开并提示升级，不做半读；单个块文件损坏只丢那一段正文，位置保留。
- 文本块目前只有 `text` 一个内容字段，字符样式、对齐、内边距还没有落盘。

## 导出容器

```text
魔术字 | 格式版本 | 目录表 | 块数据 | 媒体数据
```

- 目录表记录每个块的类型、偏移与长度。
- 自包含：画板引用的所有块与媒体都在容器内，不依赖外部文件。
- 读取时先读头部，再按需解码块，不必整包解析。

## 版本与迁移

- 格式版本写在容器头部，整数递增，只在对外发布时变化。
- 迁移颗粒度是发版：开发期间的格式变化不写迁移；本次发布与上一次发布格式不同时，才提供迁移。
- 读旧写新：打开旧格式文件，迁移后保存为当前版本。
- 迁移失败不覆盖原文件。
- 旧应用遇到更高格式版本：拒绝打开并提示升级，不做半读。
- 每次对外发布归档该版本的样例文件，作为迁移测试输入。

## 未知内容

- 未知块类型、未知字段：保留原始字节与类型编号，写回时照抄。
- 未知引用目标：标记为悬空，不删除内容。
