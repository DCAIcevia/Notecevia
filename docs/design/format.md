# 格式规范

范围：工作区存储与导出容器。规范公开，其他软件可据此实现读写。

## 基本单位

- 一切内容都是块（block）。文本是块，图片是块，视频、音频、表格、形状、高亮都是块。
- 块分两类：**共享块**按内容寻址，多篇笔记引用同一份；**私有块**按 id 命名，随笔记走。
- 共享块：图片、视频、音频。私有块：文本、表格、形状、高亮。

## 画板

- 一个画板 = 一篇笔记。
- 画板只存目录，内容在块里；目录项记录块类型、块地址与摆放。
- 画板文件字段：格式版本、类型标记、标题、标签、最后更新时间、目录项。
- 正文不在画板文件里，按需读取；列表页只读画板文件就能画出列表。

## 目录项

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | 整数 | 目录项标识，画板内唯一，删掉也不复用 |
| `block_type` | 整数 | 块类型编号 |
| `block_ref` | 文本 | 块地址，工作区内的相对路径，正斜杠分隔 |
| `x`、`y`、`w`、`h` | 浮点 | 世界坐标里的位置与尺寸 |
| `rotation` | 浮点 | 绕块中心顺时针旋转的弧度，可省，默认 0 |
| `z_index` | 整数 | 层级，大的画在上面；同层按目录顺序 |
| `locked` | 布尔 | 锁住的块不能拖动、缩放、旋转，可省，默认假 |
| `visible` | 布尔 | 隐藏的块不画、不响应点击，可省，默认真 |

- 读盘时优先用 `block_ref` 定位块文件；没有这个字段的旧文件按 `<画板>-<块>` 拼。
- `block_ref` 来自文件，不能直接当路径用：绝对路径、盘符与 `..` 一律拒绝。

## 块

- 共享块：按内容哈希命名，不可变；换一张图就是新哈希、新块。
- 私有块：按 id 命名，可编辑；编辑后写回同一 id。
- 块内容编码：CBOR，一律定长形式，映射的键是文本。
- 写盘顺序是先块后画板，每个文件先写 `.tmp`、落盘后改名。画板文件最后落地，所以中途失败最多留下没人引用的块。
- 保存是增量的：只写正文变过的块文件；画板文件每次都会整份重写（目录项可能变了）。没改动的块文件保持原样，未知字段也照旧。
- 画板文件损坏是错误，拒绝打开；单个块文件损坏只丢那一段正文，位置保留。

## 块类型

| 编号 | 类型 | 共享 | 内容字段 |
| --- | --- | --- | --- |
| 1 | 文本 | 否 | `text`、`font`、`size`、`color`、`background` |
| 2 | 图片 | 是 | `media`、`name`、`fit`（`cover`／`contain`／`fill`） |
| 3 | 视频 | 是 | `media`、`name`、`bytes` |
| 4 | 音频 | 是 | `media`、`name`、`bytes` |
| 5 | 表格 | 否 | `rows`、`cols`、`cells`（行优先的文本数组） |
| 6 | 形状 | 否 | `shape`（`rect`／`ellipse`／`line`）、`fill`、`stroke`、`stroke_width` |
| 7 | 高亮 | 否 | `color`、`opacity`（0 到 1） |

- 颜色一律写成 `#rrggbb`。
- 文本的样式字段都可省：省掉表示跟随界面主题。
- 视频与音频共用同一种正文，种类由目录项的 `block_type` 决定。
- 编号 100 以上留给扩展。

## 工作区布局

```text
工作区/
  boards/<board-id>.board              目录（CBOR）
  blocks/<board-id>-<block-id>.block   私有块（CBOR）
  media/<sha256>                       共享块原始字节
  thumbnails/<board-id>.png            画板缩略图，可删，删了会重新生成
  index.cbor                           列表与搜索的索引，可删，删了会重建
  exports/                             手动导出的容器、HTML 与图片
  .trash/<时间戳>-.../                  删掉的画板与孤儿块，不直接删
```

- 工作区就放在程序所在目录的 `NoteceviaData` 里，随程序走：整个文件夹拷走就换了机器。
- 程序目录不可写时打开失败并提示路径，不把数据偷偷写到别处——悄悄换了位置，用户以后找不到自己的笔记。
- 块编号只在画板内唯一，所以文件名带上画板号，多张画板的块不会撞车。
- 拖入的媒体复制进媒体池，按内容哈希去重，不引用外部路径。
- 保存成功后，本画板不再被引用的块文件移进回收站；媒体不回收，同一份内容可能还被别的画板引用。
- 媒体文件按哈希命名，写入前校验哈希，读不到时界面画占位，不让整张画板打不开。

## 索引

- `index.cbor` 是缓存，不是数据源：删掉或写坏都能从画板文件重建，不影响内容。
- 索引有自己的格式号（当前 3）；内容是一张画板一行：id、标题、标签、更新时间、目录项数量、可读标记、有没有缩略图、可搜索片段，外加 boards/ 目录的修改时间。
- 可搜索片段按目录顺序收：文本块正文、表格的非空单元格（整表一段）、媒体块的文件名。只改可搜索范围也要升索引格式号，旧索引会被丢弃重建。
- 用「boards/ 目录修改时间 + 画板文件数」判断有没有被外部改动；对不上就整份重建。只比对目录级信息，不逐板 stat，打开成本与画板数量基本无关。
- `save_at`、删画板、导入容器、写缩略图之后更新对应条目，整份原子重写。
- 索引只在打开工作区后第一次用到时校验一次；外部新增、删除、改名画板（包括原子改名）会改目录时间或文件数，打开时自动发现；原地覆盖写不改目录时间，打开时发现不了，要点「刷新」（Ctrl+R）强制重建。停在首页时每 2 秒也会轮询一次目录时间。

## 缩略图

- `thumbnails/<board-id>.png`，保存后生成，宽度 320 像素；生成时把视图临时缩到内容全貌再截图，完成后立刻还原。
- 缩略图是界面缓存：删掉不会影响画板，下次保存会再生成。
- 删画板时缩略图一起进回收站，避免画板编号复用时旧图张冠李戴。

## 导出容器

```text
魔术字 "NOTECEVIA-CONTAINER\n" | 版本号 1 字节（当前 2） | 重复的文件段
文件段 = 相对地址长度(u32 小端) | 相对地址 | 内容长度(u64 小端) | 内容
```

- 自包含：画板、它引用的块与媒体都在容器里，不依赖外部文件。
- 相对地址在解码时校验，只接受工作区内的路径。
- 导入时分配新画板编号并重写 `block_ref`，媒体按哈希写回媒体池，已有相同内容就不重复写。
- 容器里没有额外的目录表，读取要顺序扫；画板规模变大后再加偏移索引。

## HTML 导出

- 一张画板一个自包含文件，图片与音视频用 data URI 内嵌，断网也能看。
- 布局按世界坐标绝对定位，旋转用 CSS `transform`；隐藏的块不导出。
- 媒体缺失时留一句提示，不让整份导出失败。

## 图片导出

- 当前画布导出成 PNG，只含画布区域，不含顶栏。
- 画布上的操作提示与缩放读数属于界面叠加层，会一起被截进图里。

## 版本与迁移

- 当前格式号 **2**。格式号写在画板与块文件里，整数递增，只在对外发布时变化。
- 读到更高的格式号：拒绝打开并提示升级，不做半读。
- 读旧写新：打开旧格式文件，迁移后保存为当前版本；迁移失败不覆盖原文件。
- 迁移在内存里做，写成一个显式步骤（补字段、改格式号），不生成迁移副本；旧文件真正变成新格式要等一次保存。
- 迁移颗粒度是发版：开发期间的格式变化不写迁移；本次发布与上一次发布格式不同时，才提供迁移。
- 每次对外发布归档该版本的样例工作区，放在 `fixtures/<版本号>/`，作为迁移测试输入。
- 格式 1 的样例（`fixtures/0.1.0-alpha.1/`）仍能读，测试会把它读出来再按格式 2 写回。

## 未知内容

- 未知块类型：读时跳过这一条，其余照读，不崩；保存时这一条不会写回。
- 未知字段：读时留着，写回时原样照抄（键与值都不动）；已知字段仍按当前值重写。这条覆盖画板、目录项与块正文。
- 更高格式号的文件不会被读到这一步，整份拒绝。
- 按版本号保护的前提是：加字段、加块类型必须同时升格式号。
