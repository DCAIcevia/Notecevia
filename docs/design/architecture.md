# 架构

## 模块

| crate | 职责 |
| --- | --- |
| `core` | 文档模型、块、引用、命令、撤销；不碰文件与界面 |
| `store` | 工作区读写、块池、容器导入导出、索引、迁移 |
| `ui` | 画布渲染、物件操作、文本编辑、字体与主题 |
| `app` | 入口、配置、快捷键、更新检查 |

依赖方向单向：`core` ← `store`、`core` ← `ui`、`store` ← `app`、`ui` ← `app`。

## 加载

- 打开画板：先读目录（体积小），立即绘制结构与已缓存缩略图，再填内容。
- 视口驱动：只解码视口命中的块，靠目录项的包围盒判断。
- 图片按显示尺寸解码；视频与音频流式解码，不整文件读进内存。
- 缩略图在保存时生成，列表与首屏直接读图，不碰原文件。

## 保存

- 编辑产生变更集，按块写入，只写改动的块。
- 写入用临时文件加 rename，禁止原地截断。
- 私有块内容可变；共享块不可变，新内容产生新哈希。
- 崩溃恢复：启动时扫描临时文件与未完成写入。

## 块池与回收

- 共享块是否仍被引用，由扫一遍画板目录得出，不单独维护计数文件。
- 无人引用的块移入回收站，不直接删除。

## 交互优先级

- 首屏优先：先出结构与占位，再出内容。
- 超过 100ms 的等待必须有可见反馈，空白是最差的反馈。
- 缩放是纯视图变换，不触发重排，不改变块的文档尺寸。

## 性能预算

| 指标 | 预算 |
| --- | --- |
| 冷启动到可交互 | ≤500ms（1 万条笔记） |
| 列表列出 1 万条 | ≤1.5s |
| 1 万条搜索 | ≤100ms |
| 输入到屏幕可见 | ≤16ms |
| 空闲内存 | ≤200MB |
