# UI 规则

## 立场

- 内容优先：界面为笔记让路，不为装饰留空间。
- 克制：一个界面最多一个强调元素，最多两级背景层次。
- 桌面原生：全部操作可键盘完成，命中区 ≥28×28。
- 中文优先：字体、行高、标点按中文样张验收，不以英文样张交付。

## 禁止

| 禁止 | 替代 |
| --- | --- |
| 紫蓝渐变、发光边框、霓虹描边 | 单色强调 + 边框层次 |
| 玻璃拟态、大面积背景模糊 | 实色面板 + 1px 边框 |
| 营销式首屏：大标题 + 副标题 + 大按钮 | 直接进工作区，空态给引导 |
| 卡片网格 + 16px 以上圆角 | 列表 + 分隔线，圆角 ≤8 |
| emoji 当图标 | 统一线性图标集 |
| 模态套模态 | 侧栏内联编辑或单层浮层 |
| 深色模式纯黑 #000 | 用 surface 分层区分明度 |
| 旋转、弹跳、超过 200ms 的过渡 | 只做状态与层级反馈 |
| 自绘标题栏与系统按钮打架 | 用系统标题栏 |

## 令牌

数值集中定义在主题模块，界面代码禁止出现字面值。

- 间距：4 的倍数，只用 4／8／12／16／24／32／48。
- 圆角：控件 4，容器 8，浮层 12。
- 字号 5 档：12／13／14／15／20；正文 15、行高 1.65；字重只用 400／500／600。
- 字体：界面 `Segoe UI Variable Text`，中文回退 `Microsoft YaHei UI`，等宽 `Cascadia Mono`。
- 颜色：双主题同名语义令牌——surface-0/1/2、border、text-primary/secondary/disabled、accent、danger、warn、success；正文对比度 ≥4.5:1。
- 动效：悬停 120ms、面板 160ms、浮层 200ms，ease-out；系统开启"减少动态"时降为瞬时。
- 尺寸：列表项 40／32，图标 16／20，状态栏 28，输入框与按钮 32。

颜色具体色值待首个界面定稿时回填本 skill，在此之前不允许自行拟色。

## 布局

- 三栏：导航 240 / 列表 320 / 编辑区自适应；宽 <1100 时合并为两级导航。
- 最小窗口 900×600；窗口尺寸、位置、分栏宽度必须记住。
- 编辑区最大行宽 720，超出居中。
- 每个方向最多一个滚动条。

## 交互

- 快捷键集中定义，界面内不散落硬编码。
- 破坏性操作首选可撤销；删除后给 5 秒撤销条，删除瞬间不弹确认。
- 自动保存：停止输入 800ms 触发；状态栏显示「已保存」「保存中」「保存失败」。
- 异步操作必须有进行中反馈，失败给原因与重试入口。

## 四态

每个视图四态齐全才算完成：空（引导 + 主操作）、加载（不用纯转圈超过 1 秒）、错误（原因 + 动作）、部分失败（列出失败项，其余可用）。

## 文案

- 动词开头：「新建笔记」不写「新建」；按钮与结果一致：「删除」不写「确定」。
- 错误 = 发生了什么 + 怎么办：「无法写入笔记：磁盘已满。清理空间后重试」。
- 不用感叹号、卖萌词、空话；术语统一：笔记、标签、工作区、回收站。
- 文案集中在 `crates/ui/src/strings.rs`，不散落在视图里。

## 验收

界面改动必须附四项：浅色截图、深色截图、空态截图、键盘操作路径说明。缺一项不算完成。
