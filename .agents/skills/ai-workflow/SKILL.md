# AI 协作流程

## 开工先声明

动手前输出四行，缺一行不许动：

```text
[任务] 一句话目标 + 可验证的完成条件
[读取] 计划打开的文件（≤5）与理由
[验证] 证明完成的命令
[假设] 采用的可逆假设；没有写「无」
```

## 读取

- 会话开始只读根 `AGENTS.md` 与任务直接点名的文件。不预读、不通读、不"先熟悉一下"。
- 按任务取文件：改 core 读目标模块与它的测试；改存储读目标模块与迁移测试；改界面读主题令牌与目标视图；修 Bug 读报错、栈与复现路径上的模块。
- 禁止：读 `target/`、生成物、日志；全量 `git log`；递归列目录；逐文件通读某个 crate；读第三方 crate 源码（查 docs.rs）。
- 预算（单任务）：探索读取 ≤5 个文件，检索 ≤3 次，目录列举 ≤1 次，单次读 ≤200 行。
- 超预算：停止扩展，说明「预算耗尽」与已确认／仍缺，然后提一个问题或用一个可逆假设继续。

## 定位

1. 先用符号名或报错串检索，拿到候选文件。
2. 只读命中点上下 50 行。
3. 需要第三方 API 时查 docs.rs，不凭记忆写签名。
4. 需要调用关系时读签名，不读实现。

## 假设与提问

| 档 | 情形 | 处理 |
| --- | --- | --- |
| 自决 | 命名、局部实现、样式细节 | 直接做，汇报一句 |
| 记录 | 可逆默认值：排序、快捷键、默认名 | 做，写进「假设」 |
| 必问 | 产品行为、数据格式、接口、依赖、范围、视觉方向 | 停手，只问一个问题 |

判定：做错要回滚用户数据，或要重写两个以上模块，就必须问。

## 停止条件

- 同一问题连续两次验证失败。
- 需要「必问」档的决策。
- 规则之间冲突。
- 预算耗尽且无法形成可逆假设。

停止后只汇报事实与选项，不继续试错。

## 汇报

```text
改动：文件 → 一句话
验证：命令与结果
风险：未覆盖的边界
后续：需要用户裁决的事项
```

## 禁止

- 没跑验证就说完成；把未验证说成已验证。
- 顺手重构、顺手格式化、顺手升级依赖。
- 为"以后可能用"加抽象、配置、trait。
- 发现无关问题就动手（只记录）。
- 编造路径、版本号、issue 号。

## 自检

1. 改动都在声明范围内吗？2. 验证跑过吗？3. 相关 skill 要同步吗？4. 有裸 TODO 或调试输出吗？5. 汇报写清未验证部分了吗？
