# 开工与预算

## 声明

动手前输出四行：任务与完成条件、计划读的文件（≤5）、验证命令、可逆假设。

## 读取

只读任务点名的文件。禁止 `target/`、生成物、日志、全量 `git log`、递归列目录、三方源码。三方 API 查 docs.rs。

预算：读 5 个文件、检索 3 次、列目录 1 次、单次 200 行。超出即停，说明已确认与仍缺，提一个问题或给一个假设。

## 必问

产品行为、数据格式、接口、依赖、范围、视觉方向。做错要回滚数据或重写两个以上模块，必须先问。

## 停止

同一问题两次验证失败、需要必问决策、规则冲突、预算耗尽且无假设。停止只报事实与选项。

## 汇报

四段：改动、验证、风险、后续。

## 禁止

未验证称完成、顺手重构或格式化、为将来加抽象、动无关问题、编造路径与版本号。
