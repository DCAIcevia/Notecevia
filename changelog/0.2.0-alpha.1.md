# 0.2.0-alpha.1

从"一张能写字的画布"变成"一个能装东西、能找回来、能带走的笔记应用"。

## 新增

- 七类块：图片、视频、音频、表格、形状（矩形/椭圆/直线）、高亮；原来的文字块保留
- 图片按填充、适应、拉伸三种方式摆放；视频与音频双击用系统播放器打开
- 表格单元格可编辑，可加行加列
- 层级：置顶、置底；锁定（能选中不能改）、隐藏（不画不响应点击）
- 多选：Shift 点选、空白拖框；多块对齐（六种）与等距分布（横/纵）
- 撤销重做：拖动、打字、样式、表格、插入删除都各算一步
- 画板首页：缩略图、列表、搜索标题/标签/正文（带命中片段）、标签、按标签筛选、重命名、删除确认
- 自动保存：改动 2 秒后落盘；崩溃后启动清理没写完的临时文件
- 导出：自包含容器（可再导入）、自包含 HTML、当前画面 PNG，图片与音视频内嵌
- 拖放：把文件拖进画布成为媒体块；把容器拖进首页完成导入
- 全部画板入口：顶栏按钮与 Ctrl+H 回首页
- 首页「刷新」与 Ctrl+R：外部改动过工作区时，不重开也能重建索引
- 停在首页时每 2 秒检查一次外部改动：新建、删除或改名画板后列表自己刷新
- 缩略图拍的是整张画板的内容全貌，不再受当前平移与缩放影响

## 改动

- 格式号升到 2：画板增加标签与更新时间，目录项增加锁定与可见，七类块各有自己的正文
- 媒体进媒体池，按内容哈希命名并去重
- 保存成功后把不再引用的块移进回收站，不再直接留在磁盘上
- 列表与搜索改走可重建的索引 `index.cbor`：一万张画板下列表 4ms、搜索 13ms、启动读最近画板 35ms
- 搜索覆盖表格单元格与媒体文件名，不只文本块正文
- 未知字段读时保留、写回照抄；格式 1 → 2 的迁移写成显式一步
- 空白左键拖动改为选框，平移改为滚轮或中键拖动
- 快捷键：Ctrl+D 复制、Ctrl+A 全选、Ctrl+Z 撤销、Ctrl+Shift+Z 与 Ctrl+Y 重做

## 修复

- 保存失败提示不会再被"未保存"盖住，错误优先显示
- 旧画板在界面上打不开的问题：首页列出全部画板
- 删画板时缩略图一起进回收站，不再留下会被编号复用的旧图

## 已知问题

- 视频与音频不能在应用内播放，交给系统播放器
- 缩略图只在窗口不在前台时重画：一直盯着窗口时，缩略图会停在旧内容
- 外部程序改了工作区，要重开才在列表里看到
- 一万张画板时每次保存整份重写索引约 42ms
- 空闲内存按进程工作集算是 237MB，但同机空 eframe 窗口是 261MB：200MB 预算实际上被图形栈基线占满，口径需要重新定
- 外部改动只按目录时间与文件数判断：原地覆盖写要手动刷新才看得到
- 一万张画板时冷启动到首帧 514–534ms，超出 500ms 预算；其中约 470ms 是窗口与图形栈的固定成本
- 编辑旋转过的块时会临时摆正，写完再转回去
- 旋转与拉伸没有吸附，也没有等比缩放
- 字体按名字存：换一台没装该字体的机器会回落到默认字体
