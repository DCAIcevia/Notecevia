# 0.2.0-alpha.1

从"一张能写字的画布"变成"一个能装东西、能找回来、能带走的笔记应用"，界面重做成浅色的一套外壳。

## 新增

- 七类块：图片、视频、音频、表格、形状（矩形/椭圆/直线）、高亮；原来的文字块保留
- 图片按填充、适应、拉伸三种方式摆放；视频与音频双击用系统播放器打开
- 表格单元格可编辑，可加行加列
- 层级：置顶、置底；锁定（能选中不能改）、隐藏（不画不响应点击）
- 多选：Shift 点选、空白拖框；多块对齐（六种）与等距分布（横/纵）
- 撤销重做：拖动、打字、样式、表格、插入删除都各算一步
- 菜单栏：文件 / 编辑 / 选择 / 视图 / 帮助；菜单项接的都是实际动作，没有打开笔记时相关项变灰
- 常驻的左侧边栏列表：按更新时间倒序，行内是标题与相对时间；搜索框在列表顶部，按标题与正文搜索并显示命中片段；标签与筛选；重命名、删除（进回收站）
- 右键菜单：笔记行给打开、重命名、标签、导出、删除；列表空白处给新建笔记
- 图标条的三层视图入口：页 / 册 / 书架
- 册：把页修订成册，一篇页只属于一本册；Empty book 常驻、不可删、收留所有没装订的页
- 册视图：册列表（名字与页数，Empty book 垫底）与目录（页码靠右，点一行进那一页，右键把页移出）
- 回收站保留 30 天：启动时清掉过期条目，删除的东西仍然可以找回（还原界面还没做）
- 主题文件：工作区根目录的 `theme.json` 可以覆盖界面颜色与尺寸共 23 个 token；没写的继承内置浅色，写错就报错并退回默认
- 文字块宽度随内容自适应，手动拉过宽度的块不再自动改
- 缩放：画布右下角的百分比读数与滑块，对数刻度
- 窗口图标：近黑方块里一个白色小写 n

## 改动

- 界面重做成浅色的一套：菜单栏、图标条、左侧边栏、画布内工具栏、右侧资源栏；颜色与尺寸全部取自主题 token
- 工具栏是画布内的一条：插入工具在左；导出统一收进文件菜单，不再重复入口
- 当前笔记名不再进界面栏，由窗口标题承载（"笔记名 — Notecevia"）
- 保存成功不再提示；只有保存失败出字，并且常驻
- 删除块只走键盘 Delete：块工具条不再提供删除，避免点一下选区就误删
- 图标改为手绘细线图标，不依赖图标字体
- 回收站按删除时间保留 30 天，过期自动清理，参照 Windows 回收站
- 格式号仍为 2：画板文件不因册与书架而改变；册与书架各自一种文件，自带 format 与 kind
- 媒体进媒体池，按内容哈希命名并去重
- 保存成功后把不再引用的块移进回收站，不再直接留在磁盘上
- 列表与搜索走可重建的索引 `index.cbor`：一万张画板下列表 4ms、搜索 13ms、启动读最近画板 35ms
- 搜索覆盖表格单元格与媒体文件名，不只文本块正文
- 列表虚拟滚动：一万张画板下滚动与搜索仍保持 60fps
- 未知字段读时保留、写回照抄；格式 1 → 2 的迁移写成显式一步
- 空白左键拖动改为选框，平移改为滚轮或中键拖动
- 快捷键：Ctrl+D 复制、Ctrl+A 全选、Ctrl+Z 撤销、Ctrl+Shift+Z 与 Ctrl+Y 重做、Ctrl+N 新建笔记、Ctrl+H 关闭笔记

## 修复

- 一次按键建出两张笔记：Ctrl N 在侧栏与画布各处理了一次，现在只处理一次
- 空笔记越点越多：当前已经是空白笔记时不再新建第二张
- 新建笔记后侧边栏不刷新，列表里看不到刚建的笔记
- 保存失败提示被"未保存"盖住，错误优先显示
- 删除块太容易误触：工具条上的删除去掉，只留键盘 Delete
- 删画板时缩略图一起进回收站，不再留下会被编号复用的旧图

## 已知问题

- 册与书架：不能把页装订进册（现在只能移出）、没有封面、不能排序；书架视图与回收站界面还没做
- 工具栏还没有上下文：选中块时调整格式仍然用块上浮的那一条，不是同一排
- 左侧栏的折叠按钮在图标条底部，位置不顺手
- 深色与高对比外观没做；深色需要单独设计，不从浅色反推
- 画布配色还没进主题文件，目前只覆盖界面那层
- 纸张样式（空白 / 横线 / 方格 / 点阵）没做
- 时间只有相对时间，没有分组与绝对时间，未引入日期库
- 插入图片只能拖入画布，没有文件选择器
- 资源管理器里的可执行文件图标还是默认的；窗口与任务栏已经是新标记
- 标题用不上 600 字重，等宽数字不可用（egui 限制）
- 视频与音频不能在应用内播放，交给系统播放器
- 缩略图只在窗口不在前台时重画：一直盯着窗口时，缩略图会停在旧内容
- 外部改动只按目录时间与文件数判断：原地覆盖写要手动刷新才看得到
- 一万张画板时每次保存整份重写索引约 42ms
- 空闲内存按进程工作集算是 237MB，但同机空 eframe 窗口是 261MB：200MB 预算实际上被图形栈基线占满，口径需要重新定
- 一万张画板时冷启动到首帧 514–534ms，超出 500ms 预算；其中约 470ms 是窗口与图形栈的固定成本
- 一千块画板的增量保存约 15ms（全量 1.77 秒）；副作用是应用必须准确给出改动块，漏报会让该块正文这次不落盘
- 编辑旋转过的块时会临时摆正，写完再转回去
- 旋转与拉伸没有吸附，也没有等比缩放
- 字体按名字存：换一台没装该字体的机器会回落到默认字体

## 格式

画板格式号 2。样例工作区归档在 `fixtures/0.2.0-alpha.1/`，格式 1 的样例在 `fixtures/0.1.0-alpha.1/`，仍能打开。

册与书架是两种新文件（`volumes/<id>.volume`、`shelves/<id>.shelf`），各自带 format 与 kind；画板文件不因它们改变，所以画板格式不需要迁移。
