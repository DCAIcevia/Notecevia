# 0.1.0-alpha.1

第一个对外版本：一张空白画布上能写、能存、能原样打开。

## 新增

- 无限画布：平移（滚轮或拖空白）、缩放（Ctrl+滚轮，以指针为不动点）
- 文字块：双击空白开始写，点别处或按 Esc 确认成一块；没写字自动丢弃
- 选中块：黑白虚线框与浮动操作条，操作条含字号、字体、文字颜色、文字底色
- 摆放：拖动、拖边改宽高、绕角旋转；编辑时不显示边框与操作条
- 字体：可选系统里装好的字体族；带内置点阵的字体（如宋体）会被跳过，回落到默认字体
- 文字颜色与底色：调色板含跟随主题、常见色与自定义取色
- 保存与打开：Ctrl+S 保存，关窗时保存，重开还原内容、位置与样式
- 新建画板：Ctrl+N，旧画板保留在磁盘上
- 工作区跟随程序目录（`NoteceviaData`），整个文件夹拷走即换机器
- 格式：CBOR，画板与块分文件存放，写盘先临时文件后改名

## 已知问题

- 没有自动保存，进程被强杀会丢未保存的改动
- 删块后块文件留在磁盘上，回收留到后续版本
- 编辑旋转过的块时会临时摆正，写完再转回去
- 旋转与拉伸没有吸附，也没有等比缩放
- 字体按名字存：换一台没装该字体的机器会回落到默认字体
